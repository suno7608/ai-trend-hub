<div class="lang-ko">

Cognition은 OpenAI의 GPT-6 Astra를 활용해 AI 소프트웨어 개발 에이전트 Devin의 자체 코드 테스트 능력을 강화했다. 이를 통해 엔지니어들이 검토해야 할 코드 양을 줄이고 더 빠르게 소프트웨어를 배포할 수 있도록 지원하는 것이 목표다. GPT-6 Astra는 Devin이 자신의 작업 결과를 스스로 검증하고 시연하는 능력을 향상시키는 데 핵심 역할을 한다.

</div>
<div class="lang-en" style="display:none">

Cognition has integrated OpenAI's GPT-6 Astra into its AI software development agent, Devin, to improve the agent's ability to test and validate its own code. The collaboration aims to reduce the amount of code engineers need to manually review, enabling faster software delivery. GPT-6 Astra enhances Devin's capacity to self-verify outputs and demonstrate that the software works as intended.

</div>

## Key Points

- GPT-6 Astra is integrated with Devin to enable self-testing of AI-generated code
- Goal is to reduce engineer code review burden and accelerate software shipping
- Represents a maturation of agentic AI toward autonomous quality assurance
