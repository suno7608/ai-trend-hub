<div class="lang-ko">

아마존 사이언스와 Reactor는 AWS Trainium 칩에서 실시간 자동회귀 확산(autoregressive diffusion) 기반 동영상 생성을 구현하기 위해 Neuron Kernel Interface(NKI)를 활용한 커널 중심 최적화 기법을 개발했다. 동적 형상(dynamic shapes), 메모리 접근 패턴, 캐시 관리 등 실시간 비디오 생성의 기술적 난제를 해결하는 데 집중했으며, 개발된 기법은 다양한 모델에 범용적으로 적용 가능하다. 이 연구는 AI 기반 실시간 비디오 콘텐츠 생성의 상용화 가능성을 한 단계 높이는 기술적 진전으로 평가된다.

</div>
<div class="lang-en" style="display:none">

Amazon Science and Reactor developed a kernel-centric optimization approach using the Neuron Kernel Interface (NKI) to enable real-time autoregressive diffusion-based video generation on AWS Trainium chips. The work specifically addressed technical challenges including dynamic shapes, memory access patterns, and cache management that make real-time video generation difficult. Crucially, the techniques developed are designed to generalize across different AI models, expanding their practical applicability.

</div>

## Key Points

- AWS Trainium 칩에서 Neuron Kernel Interface(NKI)를 통한 실시간 비디오 생성 구현
- 자동회귀 확산 모델의 동적 형상·메모리·캐시 문제를 해결하는 커널 최적화 기법 개발
- 개발된 기법이 특정 모델에 종속되지 않고 범용적으로 적용 가능
- AI 실시간 비디오 생성의 클라우드 인프라 기반 상용화 가능성 제고
